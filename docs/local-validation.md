# Локальная проверка перед публикацией

Проверка выполнена 5 ноября 2026 года на Node.js 24.22.2, Supabase CLI 3.0.0 и локальном Supabase/PostgreSQL 17.

Успешно выполнены:

- чистый `supabase db reset` с последовательным применением обеих миграций;
- 28 из 28 pgTAP-проверок RLS, привилегий, переходов, истории и мягкого удаления;
- создание одного постановщика и двух исполнителей через локальный Auth API;
- вход по email и паролю для всех трёх пользователей;
- загрузка трёх объектов и пяти задач из seed;
- проверка REST-видимости объектов, задач и профилей для каждой роли;
- проверка недоступности чужой задачи по известному UUID;
- запрет прямого изменения статуса и полей задачи исполнителем;
- проверка назначенного исполнителя и обязательного комментария внутри RPC;
- создание записи истории после разрешённого перехода;
- запрет удаления истории через REST даже постановщику;
- production preview маршрутов `/`, `/objects` и `/tasks/:id` с HTTP 200;
- ESLint, 15 unit-тестов, production-сборка и `npm audit` без уязвимостей.

Воспроизведение после `npx supabase@latest start`:

```bash
npx supabase@latest test db
npm run test:e2e:local
npm run lint
npm test
npm run build
```
